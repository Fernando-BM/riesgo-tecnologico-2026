# Laboratorio de Riesgo Tecnológico - 2026

Repositorio para trabajar ejercicios puntuales y el proyecto general **(NO ES EL PROYECTO FINAL)** utilizando Django.

## 📂 Estructura del Repositorio

- **/proyecto_principal**: Contiene el proyecto a desarrollar durante todo el semestre **(NO ES EL PROYECTO FINAL)**. Está dividido en múltiples aplicaciones (módulos) de Django para separar responsabilidades.
- **/YYYY-MM-DD**: Código para sesiones de laboratorio, cada carpeta sigue el formato **YYYY-MM-DD** de acuerdo a la fecha de la sesión.

## 🚀 Configuración del Entorno de Trabajo

Para ejecutar cualquiera de los proyectos, se debe leer el README.md correspondiente y configurar el entorno virtual.

## Requisitos  para ejecutar los proyectos ##
- Python
- Entorno virtual venv configurado en base al requirements.txt del correspondiente proyecto
- Django
